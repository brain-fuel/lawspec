# Reference

Technical descriptions of the language, the tools and the interfaces.

## Language

- [Language reference](language/index.md): syntax, types and data, laws and
  examples, definitions, indexed families, evidence and discharge, domain
  modeling, imports and packages, and expressions.
- [Prelude laws and algebra](prelude-algebra.md): the built-in reusable laws,
  currying, conjunction, implication and expected results.
- [Primitives](primitives.md): the scalar catalog, literals, arithmetic and
  target bridges.
- [Refinements](refinements.md): refined types, contracts and refined
  definitions.

## Tools and interfaces

- [CLI](cli.md): every `lawspec` command and option.
- [Configuration](configuration.md): `lawspec.json` and `lawspec-package.json`.
- [Compiler API](api.md): requests, results and wire encodings.
- [Native bindings](native-bindings.md): the binding configuration and each
  target's implementation contract.
- [Compatibility](compatibility.md): supported toolchain and library versions.
- [Formatting](formatting.md): the layout of generated code on each target.
