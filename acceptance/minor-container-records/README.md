# Structural readings inside containers

Seven laws and five independent table rows exercise generic List and Maybe
payloads, named-record projections and a user-defined recursive Chain. Generated
representation changes are ordinary checked recursive definitions. All 17
native targets run these requirements in normal and 32-bit compact profiles.

One specification mutant changes the first reading's value and must fail the
native law tests. A second changes the reconstruction's field label and must be
rejected by mandatory definition admission during generation.

Run `lawspec-acceptance minor-container-records [target...]`. Use
`LAWSPEC_MACHINE_BITS=32 LAWSPEC_MINIFY=1` for compact 32-bit projects.
This is a minor-version demonstration, not a release-candidate designation.

The API checks five finite Boolean laws completely. The native suite selects
property tests and examples; its Batch and Stored inputs range over unbounded
lists. Table results and sampled inputs do not prove those universal
requirements. Exhaustive-only generation must report incomplete coverage.
