              How to read these results
              
      
                A passed check held for the inputs tried. A failed check found a
                disagreement. A generated trial tries an input against a
                property; shrinking tries simpler inputs that still fail.
                Incomplete or unsupported checks need attention before you can
                draw a conclusion.
              
      
              
      
                Specific inputs are written examples. Boundary inputs try edges
                or special cases in a stated domain. A property is a claim about
                many inputs; generated trials test individual inputs against it.
                Save regression keeps a discovered failure as a named example in
                Laws.
